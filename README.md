# Spa Commerce — TĨNH Skin Atelier

Portfolio concept kết hợp hai luồng thường bị tách rời trong ngành spa:

- mua mỹ phẩm và thiết bị chăm da;
- đặt lịch tư vấn hoặc liệu trình;
- quản trị sản phẩm, đơn hàng, lịch hẹn, khách hàng và báo cáo.

## Chạy tại máy

```bash
npm install
npm run dev
```

Mở địa chỉ được in trong terminal. Khu quản trị demo nằm tại `/admin`.

## Luồng demo nổi bật

- tìm và lọc theo loại da, nhu cầu, mức giá;
- trang chi tiết sản phẩm;
- giỏ hàng, thay đổi số lượng và mã giảm giá `TINH10`;
- biểu mẫu đặt lịch;
- chat tư vấn mô phỏng;
- dashboard quản trị, cảnh báo tồn kho và xuất `.xls` tương thích Excel;
- responsive cho mobile, tablet và desktop.

Toàn bộ tên thương hiệu, sản phẩm, khách hàng và số liệu vận hành là dữ liệu mẫu
được tạo riêng cho portfolio.
